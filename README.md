# Distrify

Sistema de gestión empresarial (ERP) open source para administrar negocios: clientes, productos, ventas, compras, caja, reportes y más.

Este monorepo contiene:

- [`back/`](./back) — API backend construida con NestJS
- [`front/`](./front) — aplicación frontend

Cada carpeta tiene su propio `README.md` con instrucciones de instalación, configuración y despliegue.
