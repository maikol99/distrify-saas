# Contribuir a Distrify

¡Gracias por tu interés en contribuir! Este es un monorepo con dos proyectos independientes:

- [`back/`](./back) — API backend (NestJS). Ver [back/CONTRIBUTING.md](./back/CONTRIBUTING.md) para setup, convenciones y flujo de trabajo específicos del backend.
- [`front/`](./front) — Aplicación frontend (Vue). Ver [front/CONTRIBUTING.md](./front/CONTRIBUTING.md) para setup, convenciones y flujo de trabajo específicos del frontend.

## Antes de contribuir

Este proyecto se distribuye bajo licencia MIT con una **cláusula adicional de atribución obligatoria** (ver [LICENSE](./LICENSE)). Cualquier fork, despliegue o uso comercial debe mantener visible el crédito **"Powered by Distrify — cuyocode.com.ar"** en el footer de cada pantalla. Los PRs que eliminen u oculten esa atribución no serán aceptados.

## Reportar bugs o proponer features

Abrí un Issue usando las plantillas provistas, indicando si el cambio afecta al backend, al frontend, o a ambos.

## Reportar vulnerabilidades de seguridad

No abras un issue público. Seguí el proceso descrito en [SECURITY.md](./SECURITY.md).

## Código de conducta

Este proyecto adhiere al [Código de Conducta del Pacto de Colaboradores](./CODE_OF_CONDUCT.md).
